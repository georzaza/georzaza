## Featured Project

### Salesforce Org Migration Accelerator

A tool developed as part of my Electrical and Computer Engineering diploma thesis, focused on accelerating Salesforce-to-Salesforce data migration.

- **Focus:** Data extraction, transformation, mapping, and loading
- **Technologies:** Salesforce, JavaScript, Node.js, Vue, Python, SQL
- **Goal:** Make complex migration workflows more structured, repeatable, and easier to manage
- **Main Advantages:** By turning the field mappings to an absolute spec, all pipelines are automated, including load order, extacted fields, and overall everything that would otherwise need to be configured on other common ETL tools like Informatica, which saves up tons of time from dev work.
- **Load Order Mechanism:** An enhanced version of Khan's algorithm with edge cutting for dependent fields that would create cycles (e.g. self-reference hierarchy fields).
